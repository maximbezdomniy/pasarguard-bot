# PasarGuard Bot

Telegram-бот для автоматизации управления VPN-подписками на базе панели PasarGuard / Xray. Предоставляет пользователям интерфейс для самостоятельного получения, продления ключей и применения спецкодов, а администратору — инструменты модерации платежей и аудита пользователей.

---

## Возможности

### Для пользователей
- Авторизация по инвайт-коду с пошаговым FSM-сценарием (aiogram).
- Выдача персональных ссылок-подписок (VLESS) с поддержкой любых клиентов.
- Мульти-ключи: привязка нескольких независимых ключей к одному аккаунту.
- Контроль продления: продление ключа доступно не ранее чем за 3 дня до истечения срока действия.
- Активация промокодов с мгновенным автоматическим применением льгот.
- Встроенная документация по настройке клиентов (v2rayTun, Hiddify, NekoBox и др.).
- Двухуровневая система уведомлений: за 3 дня и за 12 часов до отключения доступа.

### Для администратора
- Inline-модерация транзакций прямо в Telegram-чате (одобрение / отклонение).
- `/admin_users` — вывод полного реестра пользователей и статусов их ключей.
- `/admin_promo_users` — фильтрация пользователей с активными привилегиями от промокодов.
- Быстрый отзыв выданных привилегий в один клик.

## Система промокодов

Конфигурация поддерживаемых типов промокодов задается в `config.py`:

| Тип | Описание |
|---|---|
| `lifetime_free` | Бессрочный доступ (генерация ключа со сроком 10 лет) |
| `permanent_discount` | Фиксированная процентная скидка на все последующие взносы |
| `fixed_tariff` | Перевод пользователя на фиксированный 6-месячный тариф |
| `limited_free` | Временный бесплатный доступ на N дней с ограничением общего числа активаций |

Каждый промокод защищен от повторного использования одним пользователем. Для типа `limited_free` ведется глобальный подсчет активаций по всей базе.

## Стек технологий

- **Python 3.11+**
- **aiogram 3.x** — асинхронный фреймворк Telegram Bot API (FSM, фильтры, inline-роутинг)
- **SQLite** — реляционная база данных (3 таблицы с внешними ключами)
- **httpx** — асинхронный HTTP-клиент для REST API PasarGuard с JWT-аутентификацией
- **asyncio** — фоновый планировщик проверки сроков действия ключей

## Архитектура базы данных

```
users
├── telegram_id  (PK)
├── username
├── tariff_group       — 'standard' | 'free' | 'fixed_6m'
└── permanent_discount — скидка от 0.0 до 1.0

vpn_keys
├── key_id  (PK, AUTOINCREMENT)
├── telegram_id  (FK -> users)
├── panel_username
├── subscription_url
└── expiry_timestamp

used_promocodes
├── telegram_id  (FK -> users)
└── code
    [PRIMARY KEY (telegram_id, code)]
```

## Установка и запуск

### 1. Клонирование и установка зависимостей

```bash
git clone https://github.com/parkhomenko-m/pasarguard-bot
cd pasarguard-bot
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка конфигурации

```bash
cp config.example.py config.py
```

Заполните переменные в `config.py`:
- `BOT_TOKEN` — токен бота от @BotFather
- `ADMIN_ID` — Telegram ID администратора
- `PANEL_URL`, `API_USERNAME`, `API_PASSWORD` — реквизиты доступа к PasarGuard API
- `AUTH_INVITE_CODE` — код первичного доступа к боту
- `SPECIAL_CODES` — словарь доступных спецкодов и их параметров

### 3. Запуск

```bash
python3 main.py
```

## Механизм обработки платежей

В проекте реализована схема подтверждения через СБП без сторонних платежных агрегаторов:
1. Пользователь запрашивает реквизиты через меню бота.
2. После отправки перевода нажимает подтверждение в интерфейсе.
3. Бот генерирует событие для администратора с кнопками валидации.
4. При одобрении бот через API выполняет создание или продление ключа в панели и уведомляет пользователя.

## Требования к окружению

Для работы требуется развернутая панель управления PasarGuard (Xray). Бот может быть запущен на любом Linux VPS с Python 3.11+ или в Docker-контейнере.
